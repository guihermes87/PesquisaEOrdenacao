# Projetos

Códigos da disciplina de Pesquisa e Ordenação (Java, C# e Python), desenvolvidos no Apache NetBeans e no VS Code.

| Projeto | Conteúdo |
|---|---|
| [`ordenacao-comparator-produtos-por-data`](ordenacao-comparator-produtos-por-data) | Ordenação de produtos por data com `List.sort()` e Comparator em lambda (Java, NetBeans/Maven) |
| [`ordenacao-comparable-pessoas`](ordenacao-comparable-pessoas) | Ordenação natural de pessoas com `Collections.sort()` e `Comparable` (Java, NetBeans/Ant) |
| [`pesquisa-ocorrencias-texto-swing`](pesquisa-ocorrencias-texto-swing) | Interface Swing que conta ocorrências de uma palavra num texto por busca sequencial (Java, NetBeans/Ant) |
| [`_rascunhos/`](_rascunhos) | Modelos vazios e esboços iniciais das aulas |
